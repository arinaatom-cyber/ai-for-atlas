КАК БЫСТРО СКАЧАТЬ СТАТЬИ

В тексте найдено 38 уникальных DOI.

Вариант 1 — самый быстрый на Windows:
1. Распакуйте ZIP.
2. Дважды щёлкните RUN_DOWNLOAD.bat.
3. Скрипт создаст папку TMT_articles.
4. PDF будут в TMT_articles\PDF.
5. Полная таблица будет в TMT_articles\metadata.csv.
6. Не скачанные автоматически статьи будут в TMT_articles\unresolved.csv.

Вариант 2 — через командную строку:
    python download_articles.py

Для другого текстового файла:
    python download_articles.py "путь_к_файлу.txt"

Скрипт:
- извлекает DOI;
- получает название, журнал, год, PMID и PMCID;
- сначала проверяет Europe PMC;
- затем Unpaywall;
- использует Crossref для библиографических метаданных;
- скачивает только легально доступные PDF без авторизации.

Часть статей может быть закрыта подпиской. Для них откройте DOI-ссылку
из unresolved.csv через университетскую сеть, библиотечный VPN или
запросите авторскую копию у авторов.
