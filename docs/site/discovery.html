Как читать таблицу

Один экран — новые TMT-проекты вне каталога. По умолчанию показаны только строки типа «Project» (PXD/PDC/MSV/IPX).

Колонки

Тип
Project — репозиторий с accession; Paper — статья без ID; Cohort — крупная когорта из литературы.
ID проекта
Accession (клик → репозиторий) и PMID (клик → PubMed). Если ID нет — «No PXD/PDC/MSV/IPX».
Год
Год публикации или submission из PRIDE/PDC или PubMed.
Название
Заголовок статьи/проекта и короткое описание (abstract / project description).
Источник
PRIDE, PDC, MassIVE, iProX или Europe PMC.
Дизайн
Дизайн образцов: tumor/adjacent, cell line, материал из LLM-разбора абстракта.
Омики
Тип омики: proteomics, phospho, multi-omics (для когорт).
Пациенты
Есть ли пациенты в тексте: да / возможно / нет.
N
Число пациентов/образцов из абстракта (авто, проверяйте вручную).
Вердикт
Candidate — в атлас; Watch — наблюдение; Exclude — не подходит.
Уверенность
Уверенность A–D: A = protein table + дизайн OK; B = файлы есть; C = watch; D = exclude.
Похож на
Похожесть на ближайший проект каталога: accession · процент (0–100%). Сравнение по метаданным/тексту (cosine). Не дубликат — только подсказка.
Соответствие
LLM-оценка atlas fit (да/возможно/нет) или cohort score 0–100 для литературы.
Анализ
ИИ-резюме абстракта + цепочка evidence (фильтры, LLM, similarity).
Данные / файлы
Наличие protein-level таблицы в репозитории или локальном mirror.
Ссылки
Прямые ссылки: репозиторий, PMID, Europe PMC.

  • Источник: PRIDE, PDC, MassIVE, iProX, Europe PMC.
  • Поиск по ID, названию, PMID, описанию и тексту анализа.

Похожесть на атлас

Для каждого кандидата считается similarity score к проектам из projects.csv (title, tissue, disease, TMT). 80%+ — очень близко; 40–60% — та же тема; <30% — новая ниша. Клик по PXD в колонке Similar — карточка в PRIDE.

Discovery использует несколько агентов: скан репозиториев, ИИ-чтение абстрактов, rule-based QC и оценку строк.

Активный LLM для абстрактов: Ollama (local)

  • Сканирование репозиториев — PRIDE, PDC, MassIVE, iProX — rule-based фильтры TMT >6-plex

  • Оценка строк таблицы — Tier A–D, evidence chain, display_fit (rules + LLM trust)
  • Когорты из литературы — Europe PMC text mining, patient cohorts

Tier A–D — rule-based, не калиброванная вероятность LLM. Benchmark — ручная разметка на hold-out.

Критерии включения

  • Homo sapiens (отклонять mouse/rat/chicken и mixed)
  • TMT/isobaric >6-plex (TMT6 и ≤6-plex — нет; TMT18 — да)
  • Global protein-level proteome (не phospho-only, не peptide-only)
  • Ткань (tumor/adjacent/normal) или линии рака; не plasma/serum/urine-only
  • Europe PMC + ID только из Data availability

Критерии исключения

  • Non-human, mixed, xenograft-only
  • TMT6 или ≤6-plex
  • Plasma / serum / urine / blood-only
  • Phosphoproteomics-only
  • Peptide-level quantification only
  • Review / methods / software без когорты
  • Phospho-only или RAW-only в репозитории
