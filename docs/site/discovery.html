Справка

Как читать таблицу

Один экран — новые TMT-проекты вне каталога. По умолчанию показаны только строки типа «Project» (PXD/PDC/MSV/IPX).

Колонки

Тип
Project — репозиторий с accession; Paper — статья без ID; Cohort — крупная когорта из литературы.
ID проекта
Accession (клик → репозиторий) и PMID (клик → PubMed). Если ID нет — «No PXD/PDC/MSV/IPX».
Год
Год публикации или submission из PRIDE/PDC или PubMed.
Название
Заголовок статьи/проекта и короткое описание (abstract / project description).
Источник
PRIDE, PDC, MassIVE, iProX или Europe PMC.
Дизайн / TMT
Дизайн и TMT plex. Если PRIDE не указал plex — жёлтый бейдж «TMT plex не прописан — нужна проверка».
Вердикт
Candidate — в атлас; Watch — наблюдение; Exclude — не подходит.
Уверенность
Уверенность A–D: A = protein table + дизайн OK; B = файлы есть; C = watch; D = exclude.
Похож на
Похожесть на ближайший проект каталога: accession · процент (0–100%). Сравнение по метаданным/тексту (cosine). Не дубликат — только подсказка.
Соответствие
LLM-оценка atlas fit (да/возможно/нет) или cohort score 0–100 для литературы.
Анализ
ИИ-резюме абстракта + цепочка evidence (фильтры, LLM, similarity).
Данные / файлы
Наличие protein-level таблицы в репозитории или локальном mirror.
Ссылки
Прямые ссылки: репозиторий, PMID, Europe PMC.

Фильтры над таблицей

  • Тип строки: все / проекты / статьи / когорты.
  • Источник: PRIDE, PDC, MassIVE, iProX, Europe PMC.
  • Поиск по ID, названию, PMID, описанию и тексту анализа.

Похожесть на атлас

Для каждого кандидата считается similarity score к проектам из projects.csv (title, tissue, disease, TMT). 80%+ — очень близко; 40–60% — та же тема; <30% — новая ниша. Клик по PXD в колонке Similar — карточка в PRIDE.
