Как пользоваться

  1. Откройте live-приложение — вкладка «ИИ поиск» открыта по умолчанию
  2. Отредактируйте ключевые слова или оставьте профиль атласа (органы, нозологии, TMT)
  3. Нажмите Run search — шаги 1–4: репозитории → Europe PMC → фильтры → LLM
  4. Проверьте ID и публикации; в CSV только через run_revisor.py add --apply
