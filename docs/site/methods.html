Поиск идёт по репозиториям и литературе. PRIDE: TMT-плекс и карточка, при необходимости статья. PDC/CPTAC: метаданные уже заполнены, но отбор тот же. MassIVE и iProX — поиск по сайту. Статьи — Europe PMC по названию и похожим. Абстракт читает отдельный агент; в таблице — только проект и краткое изложение.

Как идёт поиск

  • Поиск в PRIDE — Архив PRIDE: новые TMT-проекты вне каталога. Смотрим, есть ли TMT-плекс (7–18). Если плекс или материал не в карточке — читаем описание проекта и связанную статью.PRIDE search — PRIDE Archive: new TMT projects outside the catalog. Check TMT plex (7–18). If plex or material is missing from the record, read the project description and the linked paper.
  • Поиск в PDC (CPTAC) — В PDC болезнь, орган и TMT уже в метаданных. Те же правила включения, что для PRIDE. Поле organism в API нет: human предполагается по scope PDC/CPTAC, если нет non-human слов. Нераспознанный plex не отбрасывается на источнике.PDC (CPTAC) search — PDC already carries disease, organ, and TMT in metadata. Same inclusion rules as PRIDE. No organism field in uiStudySummary: human is assumed per PDC/CPTAC program scope unless metadata names a non-human organism. Unparsed TMT plex is not dropped at source.
  • MassIVE и iProX — Поиск по сайтам MassIVE и iProX теми же словами: TMT, human, cancer.MassIVE and iProX — Site search on MassIVE and iProX with the same TMT / human / cancer keywords.
  • Чтение абстрактов и статей — По PMID открываем PubMed / Europe PMC. LLM читает первые N абстрактов (abstract_llm_max); остальные — keyword/regex, список в контроле качества.Abstract and paper reader — From PMID, open PubMed / Europe PMC. The LLM reads the first N abstracts (abstract_llm_max); the rest use keyword/regex and are listed for curator review.
  • Отбор по правилам — Homo sapiens, TMT 7–18, ткань или раковая клеточная линия. Не прошло проверку — не показываем как проект.Rule-based selection — Homo sapiens, TMT 7–18, tissue or cancer cell line. Failed checks are not shown as projects.
  • Статьи (Europe PMC) — Поиск по названиям и похожим публикациям в Europe PMC — не замена ID репозитория.Papers (Europe PMC) — Search by title and similar papers in Europe PMC — not a substitute for a repository ID.

Что в таблице

Проект, вердикт Candidate и краткое изложение. Орган и болезнь — из метаданных или из названия/статьи. Заглушки Other / Not reported не показываем.

PDC не ставится первым автоматически: те же фильтры, что для PRIDE. В таблице нет букв A–D и меток LLM.

Критерии включения

  • Homo sapiens (отклонять mouse/rat/chicken и mixed)
  • TMT/isobaric >6-plex (TMT6 и ≤6-plex — нет; TMT18 — да)
  • Global protein-level proteome (не phospho-only, не peptide-only)
  • Ткань (tumor/adjacent/normal) или линии рака; не plasma/serum/urine-only
  • Europe PMC + ID только из Data availability

Критерии исключения

  • Non-human, mixed, xenograft-only
  • TMT6 или ≤6-plex
  • Plasma / serum / urine / blood-only
  • Phosphoproteomics-only
  • Peptide-level quantification only
  • Review / methods / software без когорты
  • Phospho-only или RAW-only в репозитории

Каталог Excel не публикуется. На сайте — только новые кандидаты, литература и анализ.
